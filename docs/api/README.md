# docs/api

- `ENDPOINT-MAP.md` — **committed.** Every DockHand operation with the tier dockhand-mcp assigns it. Generated by `scripts/gen-endpoint-map.py`.
- `dockhand-openapi-1.0.49.json` — **not committed** (`.gitignore`: `docs/api/*.json`). DockHand's own OpenAPI document (`GET /api/docs`). Sessions S1, S2, S3a and S3b need it; the maintainer either leaves a copy at this path (git-ignored, and the session greps it) or attaches it to the session. S0, S4 and S5 don't need it. To regenerate the map after a newer spec:

```powershell
python scripts\gen-endpoint-map.py docs\api\dockhand-openapi-<version>.json > docs\api\ENDPOINT-MAP.md
git diff docs\api\ENDPOINT-MAP.md   # any change = a tier decision to record in ARCHIVE §14
```
